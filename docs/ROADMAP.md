# Отложенные задачи

## Трудозатраты (методы 2А и 2Б расчёта стоимости)
Сейчас человеко-дни считаются по **черновым нормам** на раздел (`data/labor_norms.json`, `approved: false`).
Это оценка, а не норматив: в открытых источниках официальных норм трудозатрат по разделам нет.
Расчёт по реальности не соответствует. Основным остаётся метод 1 (по сборникам МНЗ/СБЦП).

**Идея решения:** проанализировать уже выполненные контракты (фактические человеко-дни по разделам АС, КМ и т.д.,
стоимость, состав проекта) и подставить в `labor_norms.json` реальные нормы, затем поставить `approved: true`.

## Этап Б (ИИ-извлечение параметров для сметы)
1. Маскирование данных перед отправкой в ИИ (`app/services/masking.py`) — сделано, ветка `stage-b-masking`.
2. Первый запрос: объекты/сооружения из ТЗ и сопоставление с позициями `data/normative_catalog.json`.
3. Второй, точечный запрос: значение параметра X, перевод единиц; если в ТЗ нет — минимальное X с пометкой «уточните у заказчика».
