## Согласованные требования из предыдущих обсуждений

### 1. Три варианта расчёта стоимости ПИР
1. **Вариант А — От стоимости строительства (СМР):**
   - Если в ТЗ указана ориентировочная стоимость строительства — подставляется автоматически; если нет — поле для ручного ввода по желанию.
   - Расчёт справочно по **Методике Минстроя РФ от 01.10.2021 № 707/пр**.
2. **Вариант Б — По сборникам базовых цен (СБЦ / НЗ):**
   - Предустановленная библиотека нормативов (включая *«Нормативные затраты на работы по подготовке проектной документации для строительства, реконструкции сетей инженерно-технического обеспечения и объектов инфраструктуры»*).
   - Возможность добавления новых сборников путём **простой подгрузки файла целиком в формате Word (`.docx`) или PDF (`.pdf`)** без ручного заполнения таблиц.
   - **Индексы изменения стоимости проектных работ (ежеквартальные):**
     - Хранятся с датой последнего обновления.
     - Рядом с полем индекса выводится ссылка на источник: [КонсультантПлюс — Индексы изменения стоимости проектных и изыскательских работ](https://www.consultant.ru/document/cons_doc_LAW_39473/?ysclid=mvp3jowdlz526904767), чтобы пользователь мог проверить и сразу вручную поправить индекс.
     - Если с даты обновления индекса прошло более 3 месяцев (1 квартал) — выводится предупреждение: *«Индексы могли устареть, проверьте актуальные значения и обновите при необходимости»*.
3. **Вариант В — По трудозатратам специалистов (2 подварианта):**
   - **В1:** Строго по Методике № 707/пр (от среднемесячной зарплаты исполнителей по региону).
   - **В2:** Внутренний коммерческий расчёт со **справочником специалистов** (стартовые значения — на основе средних зарплат по г. Тюмень / Тюменской области, с возможностью редактирования и добавления должностей).

---

### 2. Выходные документы модуля
1. **Сметный расчёт (`.xlsx` / `.docx`):**
   - Официальные формы расчёта в соответствии со структурой приказа Минстроя РФ № 707/пр (для расчётов по методике) и внутренняя калькуляция трудозатрат.
2. **Коммерческое предложение (`.docx`):**
   - **Безопасность данных компании:** в общедоступной версии (для публичного тестирования в сети) реквизиты компании не хранятся — используется нейтральный шаблон с заглушками (`ООО «Компания»`). Корпоративный бланк подключается только локально/в закрытом режиме (папка `data/private/` в `.gitignore` и `.dockerignore`).
   - **Исходящий номер:** порядковая часть остаётся пустой для ручного заполнения при отправке, а последние 4 цифры (`ММГГ` — текущий месяц и год) подставляются автоматически: `Исх. № ____/1026`.
   - **Ставка НДС:** настраиваемая (`5%` по умолчанию, `20%`, `Без НДС`).
   - **Сумма прописью:** например, `421 000 (Четыреста двадцать одна тысяча) рублей 00 копеек`.
   - **Выбор состава таблиц в КП перед формированием:**
     - Только итоговая сумма и срок (без таблицы);
     - Таблица стоимости по разделам ПД/РД;
     - Таблица по укрупнённым видам работ (техобследование, ПД+РД, инженерные изыскания, достоверность сметной стоимости);
     - Опциональное включение состава разделов или графика.
   - **Настраиваемые блоки КП:** стадия (`ПД`, `ПД + РД`, `Внесение изменений`), что входит / не входит в стоимость (чекбоксы: экспертиза, топосъёмка, изыскания и др.), срок (месяцы / рабочие / календарные дни + оговорка про время согласований), схема оплаты (аванс `N%` или поэтапно `40/30/30`), стандартные фразы со звёздочкой (включены по умолчанию).
